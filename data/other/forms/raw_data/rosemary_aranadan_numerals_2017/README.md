# SPPEL 2017 Aranadan numerals

The [Aranadan numeral page](https://lingweb.eva.mpg.de/channumerals/Aranadan.htm) in Eugene Chan's *Numeral Systems of the World's Languages* credits **Dr. Rose Mary A.**, **Swaraj Prabha**, and **Sam Robert** of the SPPEL Aranadan Language project, dated **1 March 2017**. Its HTML was downloaded 25 September 2026 and checked in as `Aranadan.htm` (28,219 bytes, SHA256 `9993eb3095d384ffde8da93d444b19588061b0a2c7cbef5245a379adad2ec35c`). The [numeralbank/channumerals v1.0.1 archival extraction](https://doi.org/10.5281/zenodo.15649312) is CC BY 4.0 and provides a citable openly reusable representation; this importer parses the checked-in primary HTML, not the automated CLDF segmentation.

The HTML table has **20 rows × 2 displayed cells = 40 cells**. The 30/31 and 200/400 cells each contain two explicit numbered items, yielding **42 audited numeral items**. **41 are installed**; numeral 60 is held because the source prints `aɽupart̪ə`, with an unexpected internal `r` that may be a typing error. We do not silently change it. The audit preserves each exact cell, numbered piece, row/column, source IPA, selected gloss, status, and uncertainty. Source numbers outside the displayed table, Chinese commentary, and inferred arithmetic components are excluded. No etymological, borrowing, or variant edges are inferred.

The source labels its language **Aranadan**. [Glottolog](https://glottolog.org/resource/languoid/id/aran1261) maps Aranadan (`aran1261`, ISO `aaf`) as a spoken L1 language, with Aranatan/Eranadans alternate names. A canonical Aranadan row uses Jambu's existing `S. Dravidian I` clade. The page gives only Kerala at state scale; no exact elicitation site or named sublect is documented, so neither coordinates nor a dialect row are invented.

The primary transcription is IPA. Raw CSV `Form` and `Phonemic` deliberately contain the same source IPA string, while `Original` derives from that string. The display profile maps IPA to Jambu notation (`t͡ʃ` → `c`, `d͡ʒ` → `j`, `aː` → `ā`, `ɽ` → `ṛ`); source `ə` is displayed as house `a`, and the original IPA remains in `Phonemic`. Dental and retroflex contrasts are retained. `Native` is blank. The source numeral IDs give stable entry keys and locators; `num` is the only grammatical tag. A seeded 20-item raw-versus-output review in `sample-audit-2026092601.json` found 0 material errors, with first/last items, both double-item cells, and the held source typo checked separately.

The source-local importer, audit, dated CSV/YAML, and profile are installed. The full CLDF build, compiled graph/reference checks, complete test suite, and browser database/app inspection are deferred under the user's prohibition on database builds and remote execution.
