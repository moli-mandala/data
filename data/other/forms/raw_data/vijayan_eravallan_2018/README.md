# Eravallan numerals: selected 2018 table and 2014 comparator

The primary page is Eugene Chan's [Eravallan numeral page](https://lingweb.eva.mpg.de/channumerals/Eravallan.htm). This package uses the exact `raw/Eravallan.htm` in immutable [numeralbank/channumerals v1.0.1](https://doi.org/10.5281/zenodo.15649312), downloaded by that archive on 12 February 2019 and licensed CC BY 4.0. Checked-in HTML is 54,179 bytes, SHA256 `6d2510a53496c222055d81bd636629d79cdbac21b4e11932397cd8d23b69ab3d`; archive ZIP SHA256 `d40ef57924f47e9d3a777955328497d4b4bfe7b4f3344211993c9b21688bfd66`. OCR did not contribute. The importer reads the primary source HTML, not automatic archive segmentations.

Two separately credited tables occupy distinct HTML sections. The selected first table credits **N. Vijayan, 24 August 2018**, and has 20 rows × two cells = 40 cells, with paired 100/200 and 400/800 labels yielding **42 explicit prompts and 42 installed readings**. The second table credits **V. Gnanasundaram, 11 October 2014**; its 40 cells yield **47 prompt readings**. All 47 are inventoried in `audit.jsonl` as excluded comparators, so the total audit has **89 prompt records**. The tables share 39 prompt numbers, of which 22 raw NFC forms are identical; most of their 17 differences concern `ɾ/r` or small vowel differences. The later table may revise or draw on the earlier one, so the source does not establish two independent elicitation witnesses. Only the later table is selected, and no cross-table variant graph is inferred. A seeded 20-prompt raw-to-parsed check records **0/20 material errors**; first/last cells, paired labels, and control-table boundaries were separately inspected.

Both tables say Eravallan; the exact selected lect matches Jambu's existing canonical `Eravallan` (`erav1242`) and [Glottolog's spoken-L1 entry](https://glottolog.org/resource/languoid/id/erav1242). The source gives broad Kerala State, India, while its commentary describes the speech area in Pollachi/Udumalpet (Tamil Nadu) and Chitoor (Kerala); it provides no actual elicitation site, so no new dialect or coordinate is inferred. The existing **454** compiled Eravallan forms cite Varghese's 2015 Palakkad survey; four compiled rows are exact display-form + numeral-gloss matches (`nālɨ` and `ārɨ` at two survey sites), without a same-print citation. The selected table adds longer numerals as independent source evidence but is not claimed to supply 42 novel lexical types.

Source IPA-like strings are preserved as raw `Original` and `Phonemic`, with NFC normalization. The draft display profile maps known length, flap, palatal and retroflex symbols while preserving source non-syllabic `i̯/u̯`, caron marks and nasalized `ɔ̃` pending a specific linguistic interpretation. `Parameter_ID` is blank: the page does not assert cognacy, etymons, donors or graph relations. No cells are blank, held, or inferred. `import_source.py` generates source-local `draft.csv` and the checked-in per-prompt audit.
