# Hill Madia (Maria) numeral table (source-stage audit)

The immutable [numeralbank/channumerals v1.0.1 archive](https://doi.org/10.5281/zenodo.15649312) contains `raw/Maria-Abujh.htm`, downloaded 12 February 2019 under CC BY 4.0. Its first numbered table is labelled **Hill Madia** and credited to **Dr Christopher Vaz, SIL International, 6 October 2011**. Source prose identifies its Bhamragad variety in Gadchiroli District, Maharashtra. [Glottolog](https://glottolog.org/resource/languoid/id/mari1414) lists **Hill Maria** as an alternate name of spoken-L1 **Maria (India)** (`mari1414`), securely accounting for the Madia/Maria spelling difference. The page gives no exact elicitation coordinates.
