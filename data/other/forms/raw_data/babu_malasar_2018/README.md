# Malasar numeral table (source-stage audit)

Eugene Chan's [Malasar numeral page](https://lingweb.eva.mpg.de/channumerals/Malasar.htm) credits **Aswini Babu**, a Malasar Bible translator, on 18 September 2018. This package uses the exact `raw/Malasar.htm` HTML from immutable [numeralbank/channumerals v1.0.1](https://doi.org/10.5281/zenodo.15649312). Its `raw/README.md` dates the archived download to 12 February 2019, and its `LICENSE` is CC BY 4.0. Checked-in source HTML is 26,916 bytes, SHA256 `dbfdb263903805590c197b387c14170e2240479760c7d85d200f047865bf0c80`; archive ZIP SHA256 `d40ef57924f47e9d3a777955328497d4b4bfe7b4f3344211993c9b21688bfd66`. OCR did not contribute. The HTML's original numbered cells, not an archive CLDF segmentation, control every form.

The page has one credited numeral table, with **20 rows × two HTML cells = 40 source cells**. One cell contains both printed prompts 400 and 800, so there are **41 numbered prompts and 41 secure readings**. Number 200 is absent from the printed table and is not reconstructed. All cells and both split prompts appear in `audit.jsonl`, with raw markup, table row/column, printed label, source form, gloss, citation and stable key. The seeded 20-prompt source comparison in `sample-audit-2026092601.json` recorded **0/20 material errors**. First/last cells and the 400/800 boundary were separately checked. There are no blank or unreadable forms, slash alternatives, borrowing labels or graph claims.

The exact source label `Malasar` matches Jambu's existing canonical `Malasar` (`mala1458`) and [Glottolog's spoken-L1 Malasar](https://glottolog.org/resource/languoid/id/mala1458). It must not be conflated with separately registered `MalaMalasar` (`mala1457`). The page gives only broad India location, with no stable elicitation site, so no new dialect or coordinate is created; existing Jambu Malasar survey dialect coordinates are not borrowed. Jambu currently has about **446** compiled Malasar rows, principally from Varghese's 2015 Palakkad survey. The compiled survey contains numerals 1–10 and 20; the Babu 2018 table adds higher numbered prompts and an independent witness. No exact display-form plus numeral-gloss overlap with the compiled Malasar rows was found with this package's draft sound profile.

The source's IPA-like spelling is preserved as raw `Original` and `Phonemic`; the profile maps known length, affricates, flap and retroflexes for display, and source `ə` to house `a`. It preserves unusual `t̠`, `t̟`, `n̠` and `ʉ` without a guessed phonological reinterpretation. `Parameter_ID` remains blank because the page makes no cognacy or etymon claim. The Malasar comments compare numeral systems generally; they do not license borrowing edges.

`import_source.py` produces the installed `data/other/forms/20260925-babu-malasar-numerals.csv` and source-local `audit.jsonl`. The paired YAML, `cldf/sources.bib` key `babu2018malasar`, and `conversion/babu-malasar-2018.txt` are registered. `source_meta.py` passed (257 settings/245 keys at registration); `tests/test_babu_malasar_2018.py` plus sound-profile and dialect tests passed **25/25**, including **41/41** scoped `parse_file` rows and zero Malasar findings in the whole profile inventory. Full `make all`, full suite, compiled graph/reference/identity checks and browser QA remain deferred under the user's no-build/no-remote instruction.
