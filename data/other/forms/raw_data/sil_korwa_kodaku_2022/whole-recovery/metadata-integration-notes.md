# Whole-report integration decisions pending acceptance

The canonical source remains `behera2022korwakodaku`. The installed source
record currently describes only the 18 target wordlists. Replace that scope
description only when the whole-report output and exclusions have final
reconciled counts. Do not silently relabel old appendix-only evidence as a
review of all narrative material.

`auxiliary-source-proposal.bib` records two authorities directly from printed
page104 of Behera. These are reported references, not claims that either
original has been obtained or ingested. Behera printed18 explicitly attributes
the Standard Sadri text to Abraham1995 AppendixC-11. Cite the actual reproduced
Behera text and retain the earlier attribution separately with its secondary
status. CTDP per-occurrence use depends on the outside-example review.
The existing key `rensch-decker-hallberg1992` already represents the methodology
authority named in printed47 note9; do not duplicate that bibliography entry
or turn its lexical-similarity rules into cognacy assertions.

The identity proposal keeps Birjia separate and preserves Tanmai as an
explicit unresolved source conflict. Its blank-coordinate Birjia proposal
requires review before any registry mutation. Kanda is a locality, so the
proposed dialect identifier should describe the locality rather than imply
that a story itself is a dialect. Existing source keys and identities remain
protected by the legacy baseline.

Current `SourceMeta.transcription_rule` chooses rules by citation and language,
then file defaults. It does not select individual entries. Therefore a global
change to the current source rule could also change the 4,458 old rows. Before
choosing a final route, inspect all new symbols and compare old parser outputs.
Do not mint a fictitious bibliographic source merely to route narrative forms,
or assume that the wordlist profile is already reviewed for every narrative
symbol. File-default routing may be possible if the existing source rule is
moved without changing its old-file behavior; that requires explicit focused
verification and is not yet applied.

All artifacts here remain proposals. No database, registry, canonical YAML,
canonical bibliography or CSV was changed by this metadata preparation.
