# Pottangi Ollar Gadaba numeral table (source-stage audit)

The primary page is Eugene Chan's [Pottangi Ollar Gadaba / Konekor Gadabar numerals](https://lingweb.eva.mpg.de/channumerals/Gadaba-Konekor.htm). This package uses the exact `raw/Gadaba-Konekor.htm` in immutable [numeralbank/channumerals v1.0.1](https://doi.org/10.5281/zenodo.15649312), whose raw HTML was downloaded 12 February 2019 under CC BY 4.0. Checked-in HTML is 77,561 bytes, SHA256 `cea3111ad32229b6e564af62c187a43e1946d4b78182201d674505c82dc2ce63`; archive ZIP SHA256 `d40ef57924f47e9d3a777955328497d4b4bfe7b4f3344211993c9b21688bfd66`. OCR did not contribute; the importer parses the original HTML cells rather than archive segmentations.

The selected first table is labelled **Pottangi Ollar Gadaba**, credited to **Varghese John, 6 March 2013**. Its 20 rows × two cells give **40 numbered prompts**. Numerals 1–3 each have three separately printed answers, giving **46 complete installed readings**. The first answer is unmarked in its cell, while source prose calls the three classes non-human, human masculine, human feminine. The second and third answers have explicit `(masc.sg)/(fem.sg)` or `(m.)/(f.)` labels. Jambu tags only the explicit masculine/feminine distinctions; singular is tagged only at numeral 1, where printed. The inferred non-human role is in the audit and is not silently turned into a grammatical neuter tag. Numeral 4 alone carries a local `< Oriya` mark, so only it gets `loanword`; the audit retains the Oriya label, with no donor-specific graph edge or inferred etymon. Although source prose says later numerals follow Oriya's system, it does not individually mark them as borrowed. Slash/gender answers are independent forms without directional variant edges.

The later table is separately credited to **S. R. Sharma, 3 December 1990**, and labelled **Konekor Gadabar**. All **40** of its numbered cells are audited as an excluded comparator; **11 are printed blank** (21–29, 200, 2000), and its nonblank cells include separate human/non-human forms. The tables are not blended or treated as independent samples of one source lect without further review. Thus the audit has **80 source cells**: 40 selected and 40 excluded. The seeded 20-target-cell review recorded **0/20 material errors**; first/last cells, all three class-marked target cells, local loan mark and comparator blanks were also inspected.

[Glottolog](https://glottolog.org/resource/languoid/id/pott1240) identifies Pottangi Ollar Gadaba `pott1240` as a spoken L1 and lists Ollari/Kondekor names; Jambu's exact canonical is `OllariGadaba` with that Glottocode. It remains distinct from Jambu `Gadaba` (`mudh1235`). The page gives only broad India location, not a secure source site coordinate, so no new dialect or point is inferred. Jambu has about **940** compiled Ollari Gadaba forms; three existing Bhattacharya 1957 rows exactly match one of the new display forms and numeral glosses (`irul` ‘two’, and `okuṭ` ‘one’ twice), but no source citation indicates dependence on John's 2013 contribution.

The source IPA-like spelling is kept as raw `Original` and `Phonemic`. The draft profile maps known length, dentals, retroflexes and source `j`/`d͡ʒ` by house conventions while keeping source `t͡s` separate from other affricates. `Parameter_ID` is blank because no etymon/cognacy claim is attached to an installed reading. `import_source.py` produces source-local `draft.csv` and per-cell `audit.jsonl` with exact markup, class labels, printed prompt IDs, answer keys, and all control blanks.

The installed source is `data/other/forms/20260925-john-pottangi-ollar-gadaba-numerals.csv/.yaml`, bibliography key `john2013pottangiollargadaba`, and profile `conversion/john-pottangi-ollar-gadaba-2013.txt`. `source_meta.py` passed (264 settings/250 keys at registration); `tests/test_john_pottangi_ollari_gadaba_2013.py` with sound-profile and dialect tests passed **25/25**, including **46/46** scoped `parse_file` conversion and zero Ollari Gadaba findings in the whole profile inventory.
