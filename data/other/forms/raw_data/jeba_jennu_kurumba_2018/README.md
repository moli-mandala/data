The page names *Jennu Kurumba* in Karnataka, India, and its comment gives Jenu Kuruba as an alternate name. [Glottolog](https://glottolog.org/resource/languoid/id/jenn1240) identifies Jennu Kurumba (`jenn1240`, ISO `xuj`) as a Spoken L1 language. Jambu had no such canonical; `Jennu Kurumba` is added, with broad Karnataka locality and blank coordinates because the page identifies no elicitation site. Jambu already has two older Jennu-labelled dialects under Kannada (`coorg` and the SIL Masinagudi JNSK survey), as well as DEN Jenu Kuruba reflexes assigned to Kannada. Their 300 compiled dialect-tagged forms remain untouched. This is a parallel source-qualified identity pending a future full-build migration review, not a claim that the old Kannada forms now belong to Jeba's canonical. No Coorg or Masinagudi point is borrowed for the 2018 table.

The archived page has **two separately credited numeral tables**. The first, Jeba's 2018 table, has twenty HTML rows with two columns; two right-hand cells each print two separate prompt IDs (100/200 and 400/800), for **42 target prompts and 42 installed readings**. The second table credits Dr. Basavaraja Kodagunti on 24 July 2015, uses a different transcription/orthography, and is excluded as a comparator: all **40 HTML cells** are preserved in the audit, including any cell containing more than one printed prompt, but none is imported or blended into Jeba's dataset. The audit thus has **82 units**: 42 target prompt segments and 40 second-table cells. The source comment and prose are outside the numbered-cell scope. The first table's numeral 26 appeared to contain an internal gap under naive HTML extraction, but raw markup shows adjoining spans `26. ip</span><span>pɐt̪t̪ɐːɾɨ`; joining without an invented space yields `ippɐt̪t̪ɐːɾɨ`.
