# Sharma 1990 Korra Koraga numerals

The [Korra Koraga numeral page](https://lingweb.eva.mpg.de/channumerals/Koraga-Korra.htm) in Eugene Chan's *Numeral Systems of the World's Languages* credits **Dr. S. R. Sharma**, Deccan College, as data provider on **3 December 1990**. The HTML was downloaded 25 September 2026 and checked in as `Koraga-Korra.htm` (27,136 bytes, SHA256 `a53cd1fc340e592bd3ebdcf53f8818ae3d22cc5b6c3020c329b7c3184b34a97c`). The [numeralbank/channumerals v1.0.1 archival extraction](https://doi.org/10.5281/zenodo.15649312) is CC BY 4.0; the importer reads the checked-in page itself.

The table has **20 rows × 2 cells = 40 numbered prompts**. **29 source readings are installed**. Eleven numbered cells have no reading: 21–29, 200, and 2000. They are recorded as `source_blank` in `audit.jsonl`, not inferred from neighboring compound patterns. The source's `oñji` is normalized to NFC `oñji` in the installed CSV while the exact raw cell remains in the audit/HTML. The seeded 20-item raw-versus-output audit found zero material errors among installed rows; first/last cells and all blank ranges are checked separately. Chinese commentary and inferred arithmetic components are excluded. The source makes no explicit cognacy or borrowing claim, so all installed rows remain unlinked.

The source explicitly names **Korra Koraga**. [Glottolog](https://glottolog.org/resource/languoid/id/korr1238) registers that name as a spoken L1 language (`korr1238`), and the page says Mudu Koraga is divergent enough to be unintelligible to Korra speakers. Jambu's older generic `Koraga` row uses Glottolog `kora1289`, which is a **family** code and has 2,329 compiled attestations with non-specific lect labels. We add a precise canonical `Korra Koraga` for these 29 explicitly identified readings, but do not reassign or reinterpret any older generic Koraga form. The page gives only Karnataka and Kerala broadly, with no exact elicitation site or separately named sublect; coordinates and a dialect row remain absent. Jambu's existing `S. Dravidian I` clade is used.

Raw CSV `Form` and `Phonemic` intentionally contain the same source transcription; compiled `Original` derives from the exact string. The display profile maps `w` → house `v`, `ɖ` → `ḍ`, source vowel length to macron, and `ə` → house `a` while retaining the source `ə` in `Phonemic`/`Original`; it preserves `ɨ` and printed `j`. `Native` is blank. Numeral IDs provide stable entry keys and locators; `num` is the sole grammatical tag. The profile inventory has no unmapped graphemes or replacements. No OCR contributed.
