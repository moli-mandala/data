# Erza / Bible Society of India Pattapu numerals (2015)

Eugene Chan's [Pattapu numeral page](https://lingweb.eva.mpg.de/channumerals/Pattapu.htm) credits **Erza**, a Pattapu Bible translator, via **George Edward** of the Bible Society of India, dated **26 March 2015**. This package uses the original HTML preserved as `Pattapu.htm` (SHA256 `065c351a516cf5350978c2b1c57ae50ea4affa0b6ee9085ee0414c294535ec77`). Its exact bytes come from [numeralbank/channumerals v1.0.1](https://doi.org/10.5281/zenodo.15649312), whose `raw/README.md` says the pages were downloaded 12 February 2019 and whose `LICENSE` is CC BY 4.0. The archive's automatically segmented analysis is not imported. The primary HTML has a reliable text layer, so no OCR was needed.

The **entire Pattapu numeral table** has 20 rows with two displayed cells each. Two cells each contain two separately numbered items, yielding **42 numbered prompts**: 1–30, 40–90 by tens, 100, 200, 400, 800, 1000, and 2000. The 200 item gives two complete slash alternatives, so **43 lexical answer rows** are emitted. There are no blank, corrupt, or held items. Chinese duplicate captions, contributor details, and prose about genetic affinity and distribution are metadata, not lexical rows. The importer records every original HTML cell, numbered item, row/column, exact source answer, clean gloss, and stable key in `audit.jsonl`. Slash alternatives do not imply a directional variant relationship. The page makes no explicit etymological or item-specific borrowing claim, so all rows are unlinked and have no borrowing edge.

This is an independent 2015 attestation from the 2013 Rebbavarapu wordlist later represented through Lindgren's 2023 comparative dataset. Pattapu already has a canonical language row (`patt1247`) and 101 compiled forms, but those cite Lindgren rather than Erza/Chan. The 2015 page gives only the broad districts Ongole, Guntur, and Nellore; it does not establish an exact elicitation site or named dialect, so no new dialect or coordinates are invented. Jambu's existing `S. Dravidian I` classification is retained; the source's broad statement about relation to Tamil does not change genealogy.

The source's IPA-like transcription remains verbatim in `Original` and `Phonemic`. The display profile maps explicit vowel length and `dʒ`/retroflex symbols while retaining dental diacritics, gemination, and the unusual superscript `ⁱ` in five and twenty-five without forcing a phonological reading. Source `ə` is displayed as house `a`, with the original phonemic value retained; this convention should be reviewed linguistically. `Native` is blank. The numeral prompt gives the stable entry key and source locator; `num` is the only grammatical tag. A seeded 20-item audit (`sample-audit-2026092601.json`) found 0 material errors, and all 42 items, including both multi-number cells and the slash alternative, were checked for completeness.

The source-local importer, audit, dated CSV/YAML, profile, bibliography, and focused tests form the local source stage. Full CLDF build, compiled identity/reference/graph checks, full test suite, and browser QA remain deferred under the user's explicit no-build/no-remote instruction.
