# Daniel 2013 Paniyan numerals

The [Paniyan numeral page](https://lingweb.eva.mpg.de/channumerals/Paniyan.htm) in Eugene Chan's *Numeral Systems of the World's Languages* credits **Stephen Daniel**, a Paniya Bible translator, as data provider on **23 March 2013**. The HTML was downloaded 25 September 2026 and checked in as `Paniyan.htm` (27,708 bytes, SHA256 `bc9b56163fe0be95b23e1c4cbff28894cf2ef1203f1503d70540ac9a51c36332`). The [numeralbank/channumerals v1.0.1 archival extraction](https://doi.org/10.5281/zenodo.15649312) is CC BY 4.0; this importer reads the checked-in source HTML, not archive segmentations.

The table has **20 rows × 2 cells = 40 numbered prompts**. **34 clear readings are installed**. Six source cells are held as typed transcription uncertainty: 8 and 28 (`ɘʈ;ʉ` with an unexplained semicolon), 18 (`ʈː̪` dental diacritic after a retroflex/length cluster), 23 (`munːnː` doubled length marks), 24 (`a̪` dental diacritic on a vowel), and 70 (`j̪` dental diacritic on a palatal). Exact source strings, rows, columns, and reasons are in `audit.jsonl`; no silent emendation or component inference was made. The seeded 20-item raw-versus-output audit found zero material errors among installed rows. First/last rows and all six held cells are checked separately. Chinese commentary is excluded.

The source calls the lect **Paniyan**; [Glottolog](https://glottolog.org/resource/languoid/id/pani1256) and Jambu register the base language as **Paniya** (`pani1256`). The 2013 page adds the first lexical rows for that canonical language in the current compiled Jambu snapshot. A sentence in the page's general commentary says “Paliyan,” but the title, table, and credited Paniya translator identify the table as Paniyan; that stray name does not trigger remapping to the distinct Paliyan language. The page's location statement is broad (Kerala/Karnataka); its detailed Sulthan Bathery address identifies the translator, not the elicitation site. It therefore does not justify a dialect row or a new source-local coordinate.

Raw CSV `Form` and `Phonemic` intentionally contain the same source IPA, so compiled `Original` derives from the exact printed string. The display profile maps source `ɪ` → `i`, `ɾ` → `r`, `ʋ` → `v`, `d͡ʒ` → `j`, geminate length to doubled house consonants, and explicit vowel length to macron. It preserves source `ɐ`, `ɘ`, `ʉ`, `ɨ`, retracted/dental marks, and `ʝ` rather than forcing an unprovided phonemic analysis; `Phonemic`/`Original` retain source IPA. The profile inventory has no unmapped symbols or replacements. `Native` is blank. Numeral IDs provide stable entry keys and locators; `num` is the sole grammatical tag. The source makes no cognacy or borrowing claims, so the rows remain unlinked.
