## Appendix B

Metadata is physical p.30 / printed p.25. Response data begin on physical p.31
/ printed p.26 and continue through physical p.68 / printed p.63. The appendix
contains 210 prompts and 16 lists: 15 Bhuksa/Rana/Thakur/Kathoria/Sunha/
Dangora/Dang/Chit Wan targets plus Standard Hindi. Exact topology is 3,360
conceptual cells (3,150 target; 210 control).

Physical p.68 / printed p.63 visibly ends the list at item 210 `they`, and
physical p.69 / printed p.64 starts Appendix C. There is no hidden continuation.

The metadata has two distinct `RNS` rows, Sisaikhara and Sisana. Response data
print the same code twice without locality suffixes. The first/second occurrence
is provisionally aligned with first/second metadata-row order and explicitly
marked medium-confidence. Metadata prints `RKM`; responses print `RkM`.

## Representation and overlap

The appendix is typeset Unicode IPA. PDF text can locate pages but is not
transcription evidence. Every accepted cell must be keyed and rechecked from a
rendered page image. The legacy `data/other/forms/20230530-tharu2.csv` contains
3,570 target occurrence rows including alternatives, collapses the two RNS
sites, and omits Hindi controls. It is comparison-only after independent entry.

Current review covers items 1-65 (1,040 cells) on physical pp.31-43. See the
block audits and README for exact results. Item 66 is next on physical p.43 /
printed p.38.
