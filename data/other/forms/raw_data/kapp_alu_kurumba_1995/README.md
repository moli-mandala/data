# Alu Kurumba numeral table (source-stage audit)

Eugene Chan's [Alu Kurumba numeral page](https://lingweb.eva.mpg.de/channumerals/Kurumba-Alu.htm) credits **Prof. Dieter B. Kapp, University of Cologne, 13 July 1995**. This package uses exact `raw/Kurumba-Alu.htm` in immutable [numeralbank/channumerals v1.0.1](https://doi.org/10.5281/zenodo.15649312), whose raw HTML was downloaded 12 February 2019 under CC BY 4.0. Checked-in HTML is 27,245 bytes, SHA256 `28a41dd60bd493765ffbdb63cd1d5d4603ba8d8ccd9e1e7d9c7e1995a67385d3`; archive ZIP SHA256 `d40ef57924f47e9d3a777955328497d4b4bfe7b4f3344211993c9b21688bfd66`. OCR did not contribute. The original HTML cells, not archive segmentations, control every reading.

The target table has **20 rows × two cells = 40 complete numbered prompts** (1–30, 40–90, 100, 200, 1000, 2000), yielding **40 rows**. There are no blank/control cells or slash alternates. The per-cell `audit.jsonl` preserves exact markup, printed label, row/column, source form, stable key and status. A seeded 20-cell comparison found **0/20 material errors**; first/last cells, 30's unusual `moaⁿttu`, 7/8's diaeresis, and 1000/2000's spacing around the printed number were also inspected. The page's statement that the system resembles Kannada does not identify a per-form donor or etymon, so no loan, variant, component, or cognate graph claim is added.

[Glottolog](https://glottolog.org/resource/languoid/id/aluk1238) lists Alu Kurumba as a spoken L1 `aluk1238`, exactly matching existing Jambu canonical `AluKurumba`. The page supplies only broad India location, not an elicitation site; no new dialect or coordinate is inferred. Jambu currently has **657** compiled `AluKurumba` forms. Six new house-display form+gloss pairs (seven old rows) match independently cited Varghese 2015 or Blair et al. 2012 attestations; the remaining **34/40 pairs** have no exact compiled match. No existing row cites Kapp's table, so this is not a same-print duplicate.

The source's IPA-like spelling remains exact as raw `Original` and `Phonemic`. The importer normalizes decomposed `ë` to NFC `ë` in the installed CSV and retains the pre-normalization string in the audit. The profile maps printed length to house macron and known retroflexes to house letters; `ë` is **preserved as distinct source quality** (long `ē̈`), because the page gives no orthography key supporting an interpretation as `e`, `ɛ`, or `ə`. The superscript nasal `ⁿ` in `moaⁿttu` is likewise preserved pending linguistic review. `Parameter_ID` stays blank.

`import_source.py` produces source-local `draft.csv` and `audit.jsonl`; only `--install` updates the dated source CSV. The installed files use `data/other/forms/20260925-kapp-alu-kurumba-numerals.csv/.yaml`, bibliography key `kapp1995alukurumba`, and `conversion/kapp-alu-kurumba-1995.txt`. Full `make all`, full suite, generated CLDF identity/reference/graph checks and browser QA remain deferred under the user's no-build/no-remote instruction.
