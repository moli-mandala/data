# Jeba 2018 Mullu Kurumba numerals

The [Mullu Kurumba numeral page](https://lingweb.eva.mpg.de/channumerals/Kurumba-Mullu.htm) in Eugene Chan's *Numeral Systems of the World's Languages* credits **Melwin Jeba**, a Bible Society of India translator, as data provider on **14 November 2018**. The HTML was downloaded 25 September 2026 and checked in as `Kurumba-Mullu.htm` (26,709 bytes, SHA256 `12d2602bed82a9ac23832cdfa7f4e9085a8d266ed785cf63e935b9b9cbbede5a`). The [numeralbank/channumerals v1.0.1 archival extraction](https://doi.org/10.5281/zenodo.15649312) is CC BY 4.0; this importer parses the checked-in primary page directly, not automated CLDF segmentations.

The table has **20 rows × 2 displayed cells = 40 cells**. The 100/200 and 400/800 cells contain two numbered values each, yielding **42 explicit numeral items; all 42 are installed**. `audit.jsonl` preserves every exact cell, piece, label, row/column, source IPA, English numeral gloss, and review status. The unusual internal space at 26 (`iɾʋɐt̪ t̪ɐːɾɨ`) and printed `20 .`/`2 000.` labels are retained in raw evidence; the integer prompt ID only normalizes the locator/key. No source value was silently emended. Numbers outside the table, Chinese commentary, and inferred arithmetic components are excluded. The source makes no cognacy, borrowing, or directional variant claim, so all 42 attestations are unlinked.

The page names the language **Mullu Kurumba** (URL/title also says Mullu Kuruba). [Glottolog](https://glottolog.org/resource/languoid/id/mull1244) treats it as its own spoken L1 language (`mull1244`), distinct from Jambu's existing `Kurumba`, which is **Attappady Kurumba** (`atta1243`). A new canonical Mullu Kurumba row uses Jambu's existing `S. Dravidian I` clade. The source only gives Kerala, Wayanad, and Nilgiri areas; no exact elicitation site or named sublect is supplied, so coordinates and a dialect row remain absent.

The source writes its forms in IPA. Raw CSV `Form` and `Phonemic` deliberately contain the same source IPA string; `Original` derives from that exact string. The routed display profile maps `d͡ʒ` → `j`, `ɾ` → `r`, `ʋ` → `v`, `ɐː` → `ɐ̄`, and source retroflexes to house notation while retaining source `ɨ`, dental marks, and nasalization. `Phonemic` retains source IPA in compiled rows. `Native` is blank. Numeral IDs give stable entry keys and source locators; `num` is the sole grammatical tag. `sample-audit-2026092601.json` records a seeded 20-item raw-versus-output check with 0 material errors; first/last items, two-item cells, and unusual spacing are checked separately.
