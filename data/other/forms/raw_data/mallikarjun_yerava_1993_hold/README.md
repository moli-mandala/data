# Mallikarjun / Bhat Yerava page — analysis only

Exact CC-BY [numeralbank/channumerals v1.0.1](https://doi.org/10.5281/zenodo.15649312) `raw/Yerava.htm` is preserved here (54,215 bytes, SHA256 `69f3c30c6b241fa4489dac350d6ce097bdc0027a943311b990a6dc8cec8c5c33`; archive download 12 February 2019). Its first 40-cell table credits **B. Mallikarjun, 22 April 2013**; its later 40-cell table credits **D. N. S. Bhat, 28 May 1999**, and explicitly says it was extracted from Mallikarjun's *A Descriptive Analysis of Yerava* (CIIL, 1993). The two lists agree in 36/40 printed cell strings; numerals 23, 24, 27 and 28 differ **only in spacing of `iruvatt` compounds**. They are one underlying witness, not two independent attestations.

The 1993 monograph is verified in the [official CIIL catalogue](https://www.ciil.gov.in/publications?page=18). Its published introductory description says the analysis is **based on Paniya Yerava speech** and separately compares Panjiri Yerava. Jambu's visually reviewed Das (1987) source maps Pani Yerava to canonical `Paniya` and Panjiri Yerava to canonical `Ravula`. Chan's page collapses the label to `Yerava (Ravula)` without specifying which subcommunity supplied these numeral cells. Assigning them to `Ravula` from the page heading would contradict the original work's stated primary lect; assigning them to `Paniya` without the original numeral section would also overreach. The old Das (1987) and DravLex (2018) rows have no proved same-print origin, but that does not resolve this language mapping.

No CSV/YAML/Bib/registry entry is installed. Before importing, inspect the original 1993 numeral section and determine whether the list is Paniya, Panjiri, or separately labelled. If licensed access becomes available, select one table presentation and audit the other as a dependent comparator; never count both as witnesses.
