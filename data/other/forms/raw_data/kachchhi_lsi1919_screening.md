# Kachchhi LSI VIII(I) screening — analysis only

Grierson's 1919 *Linguistic Survey of India*, volume VIII, part I, has a
comparative vocabulary of Sindhi dialects on printed pp. 214–231 that includes
a Kachchhi column. The [public-domain Wikimedia scan](https://commons.wikimedia.org/wiki/File:Linguistic_Survey_of_India_Vol_8_Part_1.djvu)
identifies the 1919 edition and gives the original archive item. The existing
Jambu registry maps `kcch` Kutchi to Glottocode `kach1277`; the older LSI
mapping audit also maps its `KACHCHHI` label to `kcch`. The current source-stage
inventory has one `kcch` row, a Zoller 2023 comparative citation for *baurā*
“many,” not a row from the 1919 table.

No cells from this source were installed. The original DjVu could not be
downloaded in the local shell because `archive.org` DNS resolution failed.
The Wikimedia browser preview reached scan page 230, but the image available
there did not establish a complete, sufficiently legible bounded Kachchhi
column and English-prompt alignment; an attempt to export the page asset
stalled and was interrupted. This is an access/transcription hold, not a
negative judgment about the source. There is no verified cell count or
same-print overlap count, and none should be inferred from OCR or the page
span. Resume only with a readable primary page image, then audit every target
cell, adjacent Sindhi controls, typography, and the `baurā` overlap before
registering a source package.
