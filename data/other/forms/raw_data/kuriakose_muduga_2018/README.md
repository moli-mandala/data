# Muduga numeral table (source-stage audit)

Eugene Chan's [Muduga numeral page](https://lingweb.eva.mpg.de/channumerals/Muduga.htm) credits **Siby Kuriakose** for a voice file and **Stephen Daniel** for the IPA transcription, dated 15 August 2018. This package uses exact `raw/Muduga.htm` from immutable [numeralbank/channumerals v1.0.1](https://doi.org/10.5281/zenodo.15649312), downloaded by that archive on 12 February 2019 and licensed CC BY 4.0. Checked-in HTML SHA256 is `3b240210f3bfa609450a010667030f9739bf02e8edc3f6030cbe30bd61a86b16`; archive ZIP SHA256 is `d40ef57924f47e9d3a777955328497d4b4bfe7b4f3344211993c9b21688bfd66`. OCR did not contribute. The import parses original HTML cells directly; it does not reconstruct pronunciation from the credited voice file or use later automatic archive segmentations.

The page has 20 rows × two HTML cells = **40 cells**. The 100/200 and 400/800 cells each have two explicit printed labels, yielding **42 numbered prompts and 42 secure readings**. All are reconciled in `audit.jsonl` with source markup, label, row/column, form, gloss and stable key. At 15 and 25, adjacent HTML spans split a continuous form: raw markup has no literal space at the span boundary, so the importer joins `pɑt̠inɑɲd͡ʒʉ` and `ɪɾʉʋat̠ːɪɑɲd͡ʒʉ` without inventing one. The fresh seeded 20-prompt sample includes both cases and records **0/20 material errors**. First/last cells and paired-label boundaries were additionally reviewed. No cells are blank, held, or inferred; the source supplies no variants, loans, donors or cognacy links.

The exact lect label `Muduga, Kerala, India` matches existing Jambu canonical `Muduga` (`mudu1239`) and [Glottolog's spoken-L1 entry](https://glottolog.org/resource/languoid/id/mudu1239). The transcriber's Sulthan Bathery mailing address is provenance, not the elicitation site; no new dialect or source coordinate is inferred. Jambu's **558** compiled Muduga rows are principally Varghese's 2015 Palakkad survey. The credited 2018 table is a different source; there are zero exact display-form + numeral-gloss overlaps with current Muduga rows under this profile. This does not mean the forms lack phonological or semantic similarity.

Source IPA remains in raw `Original` and `Phonemic`. The draft display profile maps known vowel qualities and lengths, semivowels, flap, retroflexes and geminate consonants by house conventions; source `ʉ` and modified `n̠`/`t̠` remain visible where a phonological reinterpretation is unjustified. `Parameter_ID` is blank. The source's prose comparing its decimal system with other languages is not a cognacy or borrowing claim. `import_source.py` produces source-local `draft.csv` and the checked-in per-prompt audit.

The installed source is `data/other/forms/20260925-kuriakose-muduga-numerals.csv/.yaml`, bibliography key `kuriakose2018muduga`, and profile `conversion/kuriakose-muduga-2018.txt`. `source_meta.py` passed (263 settings/249 keys at registration); `tests/test_kuriakose_muduga_2018.py` with sound-profile and dialect tests passed **25/25**, including **42/42** scoped `parse_file` conversion and zero Muduga findings in the whole profile inventory. Full `make all`, full suite, generated CLDF identity/reference/graph checks and browser QA remain deferred under the user's no-build/no-remote instruction.
