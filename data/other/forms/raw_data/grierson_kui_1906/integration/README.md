# Combined source-stage integration

This directory owns only a reviewable combined candidate. It is not an installer and does not change the authored/reviewed inputs or canonical files.

The fifteen-column CSV follows the existing importer contract: Language, Parameter, Form, Gloss, Native, Phonemic, Notes, Source, Cognates, Etymology, Entry_Key, Variant_Of_Key, Borrowed_From_Key, Derivation_Parent_Keys, Tags. Form retains literal source notation; a source-local profile supplies lowercase display and ṅ→ŋ while preserving Original and other source marks. Native and Phonemic remain blank unless a reviewed input explicitly supplies them. No inferred IPA, modernized spelling, ancestry, or cross-language equivalence is added.

Every physical source key survives in the audit, including printed blank cells, uncertain readings, documentary/hypothetical claims, unresolved language attribution, and source-defined line continuations. Each audit record stores its exact input record, disposition, emitted/reused entry keys, input hash, and relevant evidence keys. Joined atoms map both physical keys to the one approved emission. Expressions retain every contributing atom key. Shared physical tokens in explicit comparative interpretations are marked as interpretations, not counted as new printed tokens.

Dispositions are explicit: `emitted`, `source-blank`, `documentary`, `identity-hold`, `reference-hold`, `joined-physical-fragment`, and `reused-existing-occurrence`. A retained glyph uncertainty is ordinarily emitted with an uncertainty tag and exact source note; uncertainty is not itself an exclusion. Existing Naiki occurrences are reused only through the reviewed exact source-key mappings. No global same-spelling merge is performed.

Table keys follow the existing prompt inventory. Multiple printed answers receive deterministic `:v1`, `:v2` suffixes; this identifies alternatives without silently expanding parentheses. Prompts 195–200 resolve only the explicitly printed present-tense cross-reference to 179–184, retaining both citations and the physical bracket record. Prompts 133/136 retain printed blanks. Prompt 157 uses its independently adjudicated recovery, with its quantity caveat.

Grammar routes use the approved source-lect map. The Kalahandi historical route retains its conflicting modern identification explicitly. Joint Kanarese/Tamil suffix attribution, source Koi identification, and remaining comparator identity holds stay auditable until an explicit routing decision exists. No geographic coordinates are invented. Proposed dialect tags must be registered and parser-tested before installation.

Input readiness and hashes are generated by `prepare_scaffold.py`. The atomic join derivative is owned by rohru_finish; the grammar scope supplement by asur_finish. Root independently reviews the additional comparator spans. A combined CSV will be generated only after these inputs are available and their dispositions are reconciled. Full build, database, broad test suite, and browser gates remain deferred by explicit instruction.
