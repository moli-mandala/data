# Aheri Gondi numerals, 2018 source-stage package

The primary page is Benny Kurian's **Aheri Gondi** numeral table dated 7 September 2018 on Eugene Chan's [Aheri Gondi page](https://lingweb.eva.mpg.de/channumerals/Gondi-Aheri.htm). This package uses the exact `raw/Gondi-Aheri.htm` from [numeralbank/channumerals v1.0.1](https://doi.org/10.5281/zenodo.15649312), whose `raw/README.md` dates its download to 12 February 2019 and whose `LICENSE` is CC BY 4.0. Archived HTML: 27,733 bytes, SHA256 `d7f14d4b9f6e55674a8ba00aefb2d89963318ff3901eda3d2bdfb45e1b9ad225`; ZIP SHA256 `d40ef57924f47e9d3a777955328497d4b4bfe7b4f3344211993c9b21688bfd66`. The archived page, not a later live revision, controls every installed reading.

The page explicitly labels Aheri Gondi in Maharashtra, India. [Glottolog](https://glottolog.org/resource/languoid/id/aher1237) classifies Aheri Gondi (`aher1237`, ISO `esg`) as a separate Spoken L1 language. It is distinct from Jambu's generic `Gondi` (`gond1265`). The source gives no exact elicitation site; the canonical Aheri Gondi registry entry has broad location text and blank coordinates, and no dialect is invented for its contributor.

The sole numeral table has **20 two-column HTML rows**, but two right-hand cells each contain two explicitly numbered prompts: 100/200 and 400/800. It therefore prints **42 numbered prompts**, all with readings, and **42 rows** are installed. `import_source.py` checks the HTML hash, table/credit boundaries, expected prompt IDs, and exact row count. It joins adjacent inline text spans without inserted spaces: the apparent gaps in 3 and 23 from generic HTML text extraction are not present in the raw markup, which prints `muː` immediately followed by `ɖu` (or `ɖ` and `u`). Source 13 independently prints `pəd̪əmuːɖu`. The parser splits the 100/200 and 400/800 cells only at the separate printed number labels. The audit preserves raw cell markup, joined cell text, row/column/segment/number, parsed reading, and entry key for each prompt; it does not infer missing intermediate hundreds or component relations. A seeded 20-prompt raw-to-output check found **0 material extraction errors**; all boundary and mixed cells were inspected separately.

The table gives IPA-like phonetic forms, so raw `Form` and `Phonemic` deliberately match and `Original` retains the raw form; the profile converts clear source symbols to Jambu display conventions. Dental combining marks and open-mid `ɛ` are retained; source `ɛː` becomes house `ɛ̄`, and consonant length is doubled (for example `jː` → `yy`), while the source IPA survives in `Phonemic` and `Original`. All forms have blank `Parameter_ID`, a `num` tag, and a prompt-specific citation; the page asserts no specific etymon, donor, or variant relation. Its general note says these numerals remain comparatively Dravidian, which is not converted into an inheritance edge. Chinese labels, prose, and unprinted number compositions are excluded from the lexical import. No OCR was used.

The source-local raw HTML, importer, `audit.jsonl`, `sample-audit-2026092601.json`, and profile draft are in this directory. The dated installed CSV/YAML, canonical registry row, `kurian2018aherigondi` BibTeX record, installed profile, and focused test are registered. Focused source, sound-profile, and dialect checks pass (25 tests); `source_meta.py` validates 247 settings/237 citation keys; the full source-inventory profile audit has no finding for Aheri; and scoped `make_cldf.parse_file` converts all 42 forms without error. Full CLDF generation, compiled identity/graph/reference checks, the full test suite, and browser database/app checks are deferred under the user's no-build/no-remote instructions.
