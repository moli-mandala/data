# Edward 2019 Kumarbhag Paharia numerals

The [Kumarbhag Paharia numeral page](https://lingweb.eva.mpg.de/channumerals/Paharia-Kumarbhag.htm) in Eugene Chan's *Numeral Systems of the World's Languages* credits **Dr. George Edward**, Bible Society of India, as data provider on **27 November 2019**. The HTML was downloaded 25 September 2026 and checked in as `Paharia-Kumarbhag.htm` (29,066 bytes, SHA256 `7272af1ba79fc7108d13d7b7deb9f0c7407094c85c2b1e5ad308ba11b01f7737`). The [numeralbank/channumerals v1.0.1 archival extraction](https://doi.org/10.5281/zenodo.15649312) is CC BY 4.0. The importer reads the source HTML, not the archive's segmentation.

The table has **20 rows × 2 displayed cells = 40 cells**. The 100/200 and 400/800 cells contain two numbered values each, yielding **42 numbered prompts**. Numeral 20 prints two complete readings, `biːs / koːɽjoːnd`, so **43 independent lexical readings are installed**; they have separate stable keys without a directional variant edge. Parentheses such as `(caːr)` are the page's alternate transcription notation, not additional recorded answers; arithmetic parentheticals are likewise audit-only. The unusual `pa:t͡ʃ` source colon and printed `4 00.` spacing are preserved in raw evidence. Every item, first/last rows, two-item cells, printed parentheses, and the split at 20 are audited. No value was silently emended. Numbered prompts outside the displayed table, Chinese commentary, and inferred components are excluded. No source etymological/borrowing link is asserted, although the page explicitly notes widespread use of Indo-Aryan numerals.

The source names **Kumarbhag Paharia**. [Glottolog](https://glottolog.org/resource/languoid/id/kuma1274) treats it as a spoken L1 language (`kuma1274`) distinct from Jambu's existing `Malto` (`saur1249`, Sauria Paharia). A new canonical Kumarbhag Paharia row uses Jambu's existing `N. Dravidian` clade. The numeral page lists only Bihar and Jharkhand; it gives neither a stable named sublect nor an exact elicitation site. Coordinates and a dialect row remain absent. Kobayashi and Tirkey's separate 2006 comparative fieldwork independently confirms the distinct Kumarbhag lect label, but its wordlist was **not** imported because this author-hosted paper has no explicit reuse license for systematic extraction.

The source writes its principal forms in IPA and parenthetical alternate notation. Raw CSV `Form` and `Phonemic` deliberately contain the same principal source IPA, so compiled `Original` retains that string; the display profile maps IPA `t͡ʃ` → `c`, `d͡ʒ` → `j`, IPA glide `j` → `y`, `w` → Jambu `v`, length `ː` or the one printed `:` → macron, and retroflexes to house notation. Original `w` and the one printed `:` remain visible in `Original` and `Phonemic`. The profile inventory passes without replacement or missing graphemes. `Native` is blank. Numeral IDs give stable entry keys and source locators; `num` is the sole grammatical tag. `sample-audit-2026092601.json` records a seeded 20-prompt raw-versus-output check with zero material errors.
