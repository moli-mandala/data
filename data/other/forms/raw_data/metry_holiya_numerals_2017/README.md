# Metry 2017 Holiya numerals

[Dr. K. M. Metry's Holiya numeral elicitation](https://lingweb.eva.mpg.de/channumerals/Holiya.htm) was supplied on **26 February 2017** as principal investigator for the SPPEL Holiya language project and published in Eugene Chan's *Numeral Systems of the World's Languages*. The Holiya HTML page was downloaded on 25 September 2026; `Holiya.htm` is the pinned raw snapshot (27,849 bytes, SHA256 `399d56b0ce416464250af7dc9cbe2d0f7a3fc9bcf0bca33dd2f16b7e48e88c7d`). Its [archived numeralbank extraction, v1.0.1](https://doi.org/10.5281/zenodo.15649312), is distributed under CC BY 4.0. That archive establishes a citable, openly reusable representation; this importer reads the checked-in source HTML directly rather than inheriting automated CLDF segmentations.

The numeral table has **20 rows × 2 displayed cells = 40 cells**. Two cells contain two separately numbered items (100/200 and 400/800), giving **42 explicit numeral items**. The deterministic importer emits **39 Holiya attestations** and audits **3 held items**: 23 prints `mːra`, 60 prints `ipptta`, and 90 prints `naːkippattn u`. Those sequences may contain source typing errors but are not silently emended. The audit preserves the exact cell, printed label (including `4 00` and `2 000`), arithmetic notes, row/column, parsed source form, and typed uncertainty. Numbers outside the table, Chinese commentary, and inferred vigesimal components are excluded. These 39 rows are unlinked; the source does not assert cognacy, borrowing, or directional variant relationships.

The page calls the language **Holiya** and notes **Golari** as an alternate name. [Glottolog](https://glottolog.org/resource/languoid/id/holi1239) identifies Holiya (`holi1239`, ISO `hoy`). A new canonical Holiya row is registered under Jambu's existing `S. Dravidian I` clade. The page gives only a broad Madhya Pradesh region and no named sublect or exact elicitation site, so no dialect row or point coordinates are invented.

The source writes its forms in IPA. Raw CSV `Form` and `Phonemic` therefore deliberately hold the same *source* IPA string; `Original` derives from that exact string. The routed profile converts display `Form` to Jambu's house notation (for example `dʒ` → `j`, `aː` → `ā`, `ʈ` → `ṭ`) while preserving `ɐ`, `ɱ`, and `ʉ` where collapsing vowel or nasal qualities would lose source distinctions. `Phonemic` retains the source IPA in compiled rows. `Native` is blank. The table's own numeral labels supply stable entry keys and source locators, and `num` is the sole grammatical tag. `sample-audit-2026092601.json` records a seeded 20-item raw-versus-output check with 0 material errors; first/last items, two-item cells, and held typography have dedicated tests.
