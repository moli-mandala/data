# Betta Kurumba numerals: selected Selvaraj 1996 table

Eugene Chan's [Betta Kurumba numeral page](https://lingweb.eva.mpg.de/channumerals/Kurumba-Betta.htm) has two separately credited tables. This package uses the exact `raw/Kurumba-Betta.htm` HTML in immutable [numeralbank/channumerals v1.0.1](https://doi.org/10.5281/zenodo.15649312), downloaded by that archive on 12 February 2019 and licensed CC BY 4.0. Checked-in HTML is 74,677 bytes, SHA256 `71b89e52ea2f514aa8051081ec8631772501f6f56c05ed25f0227250e39981c3`; archive ZIP SHA256 `d40ef57924f47e9d3a777955328497d4b4bfe7b4f3344211993c9b21688bfd66`. OCR did not contribute. The original HTML cells, not later automatic archive segmentations, control the import.

The selected first table credits **Daniel Selvaraj**, Bible Society of India, **22 August 1996**, and has 20 rows × two cells = **40 explicit numbered prompts and 40 secure readings**. The later table credits **Gail Coelho, 2010/2011**, and its 40 cells are audited as excluded comparators. The Coelho table carries separate phonemic `/…/` and phonetic `[…]` layers; the audit separates those layers in 38 well-delimited cells and flags malformed delimiters at 200 and 1000. Its first cell also has a parenthesized partial. Ingesting that richer analysis would require a dedicated cell-by-cell interpretation; this package selects the bounded complete Selvaraj table and makes no claim that the two tables are independent or that one revises the other. All **80 cells** have source markup, printed labels, row/column and status in `audit.jsonl`. The seeded 20-target-cell check recorded **0/20 material errors**; first/last cells and the later-table boundary were additionally inspected. There are no blank target cells, alternatives, source-tagged loans or graph claims.

The exact source label `Betta Kurumba` matches Jambu's existing canonical `BettaKurumba` (`bett1235`) and [Glottolog's spoken-L1 entry](https://glottolog.org/resource/languoid/id/bett1235). The source gives only `India`, so no new dialect or source coordinate is inferred. Jambu already has about **398** compiled Betta Kurumba forms from Blair et al.'s 1984–85 survey (published 2012) and DravLex; the source table is differently credited. One installed candidate, `mūru` ‘three’, exactly overlaps an independently cited Blair et al. survey form in display spelling and gloss. The import is an independent source attestation, not a claim of 40 novel lexical types.

Source IPA-like strings are kept verbatim in raw `Original` and `Phonemic`. The draft display profile maps length, schwa, semivowels, flap and retroflexes by established house conventions; no unsourced phonological analysis is inferred. `Parameter_ID` remains blank because the source supplies no cognacy or etymon claims. `import_source.py` produces source-local `draft.csv` and the checked-in 80-cell audit.

The installed source is `data/other/forms/20260925-selvaraj-betta-kurumba-numerals.csv/.yaml`, with bibliography key `selvaraj1996bettakurumba` and profile `conversion/selvaraj-betta-kurumba-1996.txt`. `source_meta.py` passed (261 settings/248 keys at registration); `tests/test_selvaraj_betta_kurumba_1996.py` with sound-profile and dialect tests passed **25/25**, including **40/40** scoped `parse_file` conversion and zero Betta profile findings in the whole inventory. Full `make all`, full suite, generated CLDF identity/reference/graph checks and browser QA remain deferred under the user's no-build/no-remote instruction.
